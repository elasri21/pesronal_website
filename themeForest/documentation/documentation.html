📘 John Doe Portfolio Template - Documentation

🔍 Overview

This is a personal portfolio HTML5 template built with HTML, CSS, and JavaScript. It is fully responsive and showcases services, projects, and a contact form powered by EmailJS.

📦 Folder Structure

john-doe-portfolio/
├── css/
│   └── main.css
├── js/
│   └── main.js
├── images/
│   └── (all project images and assets)
├── index.html
└── documentation/
    └── index.html (this file)

🚀 Installation

No installation is required. Just open index.html in your browser to view the template.

To deploy the template online, upload the contents of the root folder to your preferred web host (Netlify, GitHub Pages, Vercel, etc.).

⚙️ Customization

  • Edit text content inside index.html.
  • Update colors, fonts, and layout styles in css/main.css.
  • Replace images inside the images/ folder. Ensure paths match.
  • To update project links, change the href values in the Projects section.

📬 Contact Form (EmailJS Setup)

  1. Sign up at emailjs.com.
  2. Create a new service and template.
  3. In main.js, replace "service_ID" and "template_ID" with your own IDs.
  4. Replace emailjs.init("user_id") with your actual user ID.
